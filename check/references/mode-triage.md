# Issue and PR triage
Read the actual item, current branch/release behavior and linked evidence. Distinguish a reproducible defect, duplicate, support question and proposed feature without assuming the reporter's diagnosis.
For PRs inspect the diff and relevant checks. For issues identify the smallest missing reproduction fact.
Triage does not authorize fixes, comments, labels or closure by itself. Prepare the concrete action and carry out only authorized mutations.
Use [public-reply.md](public-reply.md) for maintainer messages. Read back the target and changed state after an external action; reconcile uncertain results before retrying.
