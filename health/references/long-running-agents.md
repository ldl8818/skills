# Long-running Agent checks

Load only for an explicitly scoped persistent Agent audit. Check actual budget controls, cancellation, progress signals, retry bounds and recovery from partial external actions.
Repeated failure calls for a revised diagnosis; it does not imply a universal attempt count or immediate user handoff. A resolvable merge conflict is not automatically an external blocker.
A hook can enforce only the operations its host actually exposes. Verify coverage and bypass boundaries rather than claiming prompts or hooks cannot be skipped.
