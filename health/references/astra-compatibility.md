# Instruction compatibility
Use current AGENTS.md and the specific active Skill/configuration involved. Compare actual clauses, not filenames or model stereotypes.
Look for:
- Conflicting authority, scope, output or language requirements.
- Skills competing for one intent, broad noun-only routing and accidental chained workflows.
- Repeated approval for an already authorized task.
- Stopping at a checkpoint when the task can safely continue.
- Repeated verification of unchanged evidence or mandatory full suites for unrelated edits.
- Fixed Agent counts or blanket restrictions that prevent useful authorized parallel work.
- Model-specific assumptions without current observed benefit.
- Long unconditional references and duplicated instructions.
For each candidate name the conflicting sources and the request where the conflict changes behavior. Static tension is not proof of a runtime failure; qualify it or use a bounded scenario.
Do not add a generic Agent philosophy or scorecard. Prefer removing the conflicting clause or narrowing its trigger.
