# Scoped context inspection

Use only when independent inspection has been authorized and has a bounded deliverable. Read only the supplied scope.
Report current redacted evidence, impact, repair direction and verification gaps. Do not modify configuration, scan history or call live tools merely because an inspector was requested.
For instruction conflicts use ../references/astra-compatibility.md; for optional deterministic checks use ../references/checks.md. Do not apply a scorecard or fixed fan-out.
