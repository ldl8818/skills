# Data surfaces
Choose a chart from the user's question: bars for comparison, lines for time trends, distributions for spread, scatterplots for correlation. Label units, scope, missing values and time ranges.
Align comparable numbers consistently; use tabular figures where they aid scanning. Preserve readable labels at realistic density.
Use accessible color distinctions and meaningful legends. Do not rely on color alone for status.
Follow existing filters, tables and chart conventions. Test long labels, empty data, extremes and relevant responsive states in the rendered interface.
Keep the answer to the user's main question visible without expansion; collapse supplementary records when useful. Inspect sparse and typical data, without filling gaps with invented records or decorative content.
