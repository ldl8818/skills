# 中文文案
先确定读者、载体和原意。把主旨放在读者容易找到的位置，用具体的人、动作和事实解释判断。
删除没有信息的重复和套话；保留作者自然的节奏，不把每个人改成同一种声音。
作者已经表达的情感、口语和固定栏目名称属于原意；不得把情感强弱改成中性事实，也不得仅因命中套话词表就删改。对作者定稿按请求控制修改强度，不擅自扩大为全文风格重写。
恢复被误改的文案时，追溯该段在误改前最近的版本并逐字核对，不用更早的短版替代，也不改写无关段落。
例如，“全面赋能业务增长”若材料没有具体效果，改为已知动作“把订单汇总到同一张表”；不要补造增长数字。
例如，“我觉得这个方法还行”可保留口语态，不必升级成“该方案具有显著优势”。
标点、数字与中英文间距服从用户和项目约定。引用、代码和专名保留原样；没有禁词数量、句长或段落配额。
