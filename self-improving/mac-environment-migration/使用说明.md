# 新 Mac 分步骤引导

本目录随 [Skills 仓库](https://github.com/ldl8818/skills) 分发，可在 GitHub 选择 Code → Download ZIP，解压后进入 `self-improving/mac-environment-migration`。没有独立 release 包。仅适用于 Apple Silicon macOS；不包含安装包、私人知识或凭据，后续实现来自自己的 dotfiles 仓库 `bin/restore setup`。

## 开始与续跑

将整个 `bootstrap` 文件夹复制到新 Mac（可以用 U 盘）。打开 macOS「终端」，输入 `/bin/sh `，拖入 `setup.command`，回车。终端拖入时会处理路径中的空格；手工输入时须给路径加引号：

```sh
/bin/sh "$HOME/Downloads/bootstrap/setup.command"
```

首次按系统提示安装 Command Line Tools 和 Homebrew。Ghostty 就绪后切到 Ghostty，再运行同一脚本。脚本检查现有安装，不重复安装已经可运行的软件。若已有文件冲突、安装不完整或 Python 版本过低，处理提示后仍用同一入口续跑。

登录 GitHub 后输入配置仓库的 `owner/repo`，不要输入 token。首次只克隆配置源，不执行全量 chezmoi apply。已有配置源须包含 `bin/lib/setup.py`；旧版本会明确停止，不调用旧网关流程。当前代码若尚未推送，请携带核验过的配置工作树，不能从旧远端取得未提交改动。

后续引导只询问一次组件选择、知识库地址／分支和新机目录。默认选择 Codex、Claude Code、Obsidian；Hermes 和 Doraemon 须显式选择。私人选择与逐项结果保存在新机 `~/.config/mac-setup/state.json`，目录0700、文件0600，拒绝放在 Git 工作树中。旧机的状态文件不能当作新机完成凭证。

## 软件、知识和配置

- Codex、Claude Code 使用官方独立安装器。Hermes 使用官方安装器的固定安装阶段，排除网关、桌面和配置向导；不搬旧 venv。登录由用户直接在对应客户端完成。
- Obsidian 安装后，知识库通过 GitHub 克隆；选择 USB 时，先人工复制完整知识库到本地目录，保留 `.git` 和 `.obsidian`。目标已有内容时不覆盖；已有仓库核对来源和分支，不自动拉取或重置。
- 自有 Skills 来源使用本仓库包含5个冻结版及安装入口的版本，引导可从 GitHub 克隆到新机 `~/dev/skills`。若携带旧工作树，先核对版本和未提交内容，不自动覆盖或更新。
- Shell、Ghostty 字体／配置、规则、选定 Skills、Hook 与核心记忆分别应用。现有文件与目标不同时停止该项；只允许替换本入口刚生成且内容指纹未变的安装器默认文件，以及第一阶段的单行 Homebrew 接线。
- 新机客户端配置从现有源渲染，排除旧项目信任、桌面专用 MCP／通知、HUD 和插件运行时。只接入已经恢复的接力、文案及 Doraemon Hook。Hermes 保留 CLI 模型／记忆设置和核心记忆，排除业务 Hook、网关和旧角色启动器。逐项来源保存在同一私人清单中。
- 配置变体只用于新机，不会覆盖旧机配置源中的完整功能。Doraemon 的知识根跟随用户所选目录；知识中其他旧路径及版本复核由现有 doctor 提示，不能复制旧验证结果冒充新机通过。

## 查看结果

失败或待操作会保留在私人状态文件。退出码20表示仍有登录／人工验收等待办，30表示入口错误，64表示参数错误。`bin/restore status` 仍是旧网关状态，不代表新机环境状态。

打开 Obsidian 前先检查社区插件和旧路径，再手动选择“打开文件夹作为仓库”。核对笔记及必要附件、Git 身份与拉取；自动同步、推送测试和业务任务启用另按具体授权处理。脚本不会自动打开知识库或启用插件。

实际完成还需：三个选定 AI 客户端登录和新会话读取配置／规则／知识；Obsidian 启动、笔记与附件可读；Doraemon 的 doctor 与真实事件验证。命令版本和配置文件校验通过不能替代这些结果。

实际检查完成后，在已取得的 dotfiles 目录运行 `bin/restore setup --verify`，重查后逐项记录人工验收；报告注明证据来自用户确认。软件版本、所选目录或配置变化后，旧确认失效。没有完成就不要输入 yes；普通续跑不会自动替你确认。

## 当前验证边界

已提供模拟安装失败分支、真实 chezmoi 的干净 HOME 配置及重复执行测试；系统安装不在更换 HOME 的隔离范围内。本轮没有在旧机重装软件，真实官方安装和新 Mac 验收仍待目标机执行。

安装依据（2026-09-12核对）：[Homebrew](https://docs.brew.sh/Installation) 、[Ghostty](https://ghostty.org/docs/install/binary) 、[Codex CLI](https://learn.chatgpt.com/docs/codex/cli) 、[Claude Code](https://code.claude.com/docs/en/setup) 、[Hermes](https://hermes-agent.nousresearch.com/docs/getting-started/installation) 。
