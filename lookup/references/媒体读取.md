# 图片、视频与嵌入媒体读取

仅在图片、图表、画布或视频画面承载用户所需信息时读取。纯文字问题已有足够证据就直接交付；字幕与 ASR 见 [youtube-subtitles.md](youtube-subtitles.md)，目标内容等待和嵌入上下文见 [动态页面读取.md](动态页面读取.md)。

## 选择证据

| 用户需要 | 优先取得的证据 |
|---|---|
| 文章观点或视频口述 | 已有正文、字幕或转写；不为流程固定补截图 |
| 图片中的文字、图表或细节 | 与目标对应的实际图片；需要布局上下文时再取页面／元素截图 |
| 某个时刻的界面变化、动作或演示 | 同一视频相关时间点及前后的实际画面，保留时间定位 |
| 声音、语气或音效 | 实际音频；静帧、字幕和元数据不能代替 |

## 图片与画布

1. 定位目标容器，核对图片与文章／对象的对应关系。接口允许时查看 `currentSrc`、`srcset` 或懒加载属性，区分缩略图、占位图与当前实际资源，不枚举整页无关媒体。
2. 尚未加载时，按需将目标滚入视口或进行正常展开，并有界等待实际图片就绪。可检查加载状态和 `naturalWidth`／`naturalHeight` 等尺寸线索；`complete`、URL 存在或一次滚到底都不能单独证明目标图已加载。
3. 公开且允许独立访问的资源，可用已有读取工具定向查看；先确认返回的是所需图片而非 HTML 验证页。直接读取失败但浏览器可见时，使用同一授权会话的元素截图，不导出 Cookie 或把认证资源交给第三方。
4. 图表、canvas 或 CSS 背景等没有独立可读资源时，按当前工具能力截图；需要比较布局时保留必要上下文。实际查看取得的图像后才解释画面，截图 API 成功不能代替视觉读取。文字过小、遮挡或内容不全时，仅对影响结论的区域补证。

`blob:` 是当前浏览器上下文中的资源标识，不能当公网 URL 发给 Reader 或外部下载器。签名 URL、登录资源和内网页面沿用原数据外发边界；拿到媒体地址不等于已获公开分享或长期归档授权。

用户明确要求下载图片时，只保存指定对象的目标图片，使用独立目录并保护已有文件。核对下载响应确为图片、实际文件可解码且尺寸有效；按原页面顺序核对数量，避免把封面缩略图、重复轮播节点或验证页当成原图交付。未取全时列明已保存与缺失范围；访问令牌不写入对外文件名或引用。

## 视频时间点与采帧

优先使用已可用且能保留时间定位的原生视频能力。确需浏览器采帧时，按 [浏览器选路.md](浏览器选路.md) 选择执行环境，再核对其当前接口是否支持播放器、frame 与截图；不假设任意站点都有可操作的顶层 `<video>`。

1. 确认同一视频、正确播放器和时间轴；广告、预告、直播与正片分别判断。核对元数据已加载、时间是否有限、目标时间是否在可定位范围内；`duration` 未知／无限时不盲跳片尾。
2. 只在已授权控制的播放器里定位所需时刻。可以求值时，按需读取 `duration`、`currentTime`、`seeking`、`readyState`、`videoWidth`／`videoHeight`；先设置有界等待，再定位时间，避免漏掉很快触发的事件。已经处于目标时刻时，不等待一个不会再次触发的 `seeked`。
3. 等待定位结束并核对目标时间与画面已更新，不能刚设置 `currentTime` 就截旧帧。支持时可用 `requestVideoFrameCallback` 的帧时间作辅助；不支持或未触发时按实际画面确认，不能无限等待回调。`seeked` 只证明定位完成，不独自证明截图呈现了新帧。
4. 围绕问题选少量相关时间点。解释“变化”至少核对相关前后画面；单个静帧不能证明连续动作、全片内容或音轨。交付标明视频来源、实际采样时间与未覆盖部分，不以离散采样声称已看完整视频。

黑屏、旧帧、DRM 限制、自动播放受阻或工具缺少媒体能力时，保留具体限制，交付字幕等独立证据支持的部分；不伪造画面，不绕过保护或反复触发播放。只管理本任务已证明归属的页面与临时素材，沿用正式接口收尾；普通内容总结不默认下载完整视频或批量图片。

## 依据

定向媒体与视频采样思路参考 [web-access 2.6.0](https://github.com/eze-is/web-access/blob/d173a75978ceb2c63fa0b27f7408cd2bf7fe4310/SKILL.md)。技术语义见 [图片 naturalWidth](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/naturalWidth)、[seeked](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/seeked_event) 与 [requestVideoFrameCallback](https://developer.mozilla.org/en-US/docs/Web/API/HTMLVideoElement/requestVideoFrameCallback)；这些是页面能力，不代表当前宿主已暴露相应接口或通过真实站点验证。
