# 浏览器选路

所有浏览器任务统一从 Lookup 进入；任务确需网页渲染、交互或浏览器证据时读取本文件。搜索与内容验收见 `SKILL.md`，授权及安全边界遵循全局规则。Ego、宿主 Browser 和其他工具只负责选中后的执行，其随附文案不另行决定优先级。

## 按任务选择

| 条件 | 执行动作 |
|---|---|
| 用户指定浏览器、账号或已有目标标签页 | 使用指定且已授权的环境；不可用时说明具体限制，不静默迁移账号 |
| 专用官方资料、已连接 API、CLI 或本地正文已经适合任务 | 先使用该路径；已有足够内容时不再启动浏览器 |
| 本机日常外部网站需要渲染、交互或常用登录态 | 默认使用与安装版本匹配的正式 `ego-browser` Skill |
| Codex 桌面端的本地页面开发、元素标注或 UI 验收，且用户未指定其他环境 | 优先使用当前会话可调用的内置 Browser，核验截图、视口和交互能力；保留已有标注及项目上下文 |
| 其他宿主的本地预览，或 console／network／performance 调试 | 按所需能力选择宿主 Browser、DevTools 或 ego；仅能打开面板不等于能操作或截图 |
| ego 技术不可用或能力不足以完成任务 | 选择能绕开已确认故障的独立、已授权浏览器能力 |
| Agent 在远端／云端运行，不能访问本机 ego | 使用该环境实际可用且已授权的浏览器；不因本机安装了 Skill 就宣称远端可用 |

## 使用与验收

- 默认 ego 不等于强制唯一；不得为了遵守品牌顺序跳过用户指定环境、专用能力或更合适的开发流程。
- 使用前读取当前宿主工具说明或正式安装 Skill；确认操作、快照／截图、上传／下载和收尾接口。仅能打开网页不证明能自动操作，框架本身支持也不证明宿主已暴露该能力。
- 本机日常外部网页可直接尝试正式 ego 接口，无需先穷举所有宿主工具。真实调用失败后按错误定位，不因 Skill 目录存在就宣称浏览器、登录态或目标内容已通过。
- 换路前比较实际浏览器进程、Profile、账号、网络和桥接依赖。仅 OpenCLI adapter／bridge 失败时，正式 ego 接口可能独立；ego 进程或同一账号失效时，不靠换同一依赖重试。具体作用域见 [failure-domains.md](failure-domains.md)。
- 权限拒绝、账号挑战或用户接管时停止相关操作，按当前工具的交接机制处理；不得把授权边界当技术故障切换工具绕过。
- 只管理本任务已证明归属的页面／空间，遵循正式接口的资源预算与收尾约定。ego 的加载和兼容入口见 [ego-space-hooks.md](ego-space-hooks.md)。
- 普通 DOM 内容按需取语义快照；布局、图片、画布或视频画面需要相应视觉证据。未获取的内容明确留缺口，不能从能打开页面推断已读取完整媒体。
- 目标内容尚未出现、遇到登录提示或 frame／组件边界时读 [动态页面读取.md](动态页面读取.md)；所需信息在图片或视频画面中时读 [媒体读取.md](媒体读取.md)。两者只指导已选环境的读取与验收，不另设浏览器优先级。
- 对比浏览器能力时分别记录官方声明、当前环境实际暴露的接口和同任务实测。保留模型、版本、输入、成功条件、完整耗时与失败记录；不以一次探活、工具调用次数或厂商图表推导全面更强。
