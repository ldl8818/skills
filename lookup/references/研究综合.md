# 多来源研究与资料综合

仅在用户要求研究问题、比较多份来源、整理资料或形成参考文章时加载。普通搜索、单链接摘要不需要这些步骤。

- **先确定交付问题**：从用户请求判断要回答什么、面向谁、需要笔记、比较结论还是文章。低风险细节直接判断，只有缺失信息会改变研究方向或交付物时才询问。
- **按证据缺口取材**：优先原始论文、官方资料、作者原文和可验证实现；二手材料可帮助发现线索，但不能冒充一手证据。已有材料够用就不重复搜索，不设固定来源数量或要求通读无关全文。
- **将主张对应到来源**：重要结论保留出处、版本或日期；搜索摘要只作初筛。区分来源陈述、本轮核验和推断，未读到的内容不写成已确认。
- **解释而非拼接摘要**：围绕问题组织概念、关系、适用边界和必要例子。文章较长时先理清结构，关键段落要有材料支持；发现缺口就定向补查，不重新跑完整流程。
- **保留分歧与未知**：来源矛盾时说明各自证据、时间和适用条件；无法判定就保留不确定性，不靠多数转载或自行选边制造定论。
- **按请求完成交付**：检查论证是否连贯、例子是否有依据、引用能否回查，以及读者是否能据此理解或行动。简短参考不强制写成长文，也不承诺“一篇覆盖所有问题”。

保留作者原意与事实，不编造经历、引用或产品状态。研究交付不自动授权发布、上传、扫描历史会话或写入长期记忆；用户提供的会话材料只在指定范围内处理。

本文件吸收已退役 Waza `learn` 中的来源追踪、结构化理解、分歧保留与交付边界，未保留六阶段编排、固定来源数量或强制串联其他 Skill。原作者许可见 [LICENSE-waza](../scripts/LICENSE-waza)。
