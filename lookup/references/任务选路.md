# 任务选路与后端资料

多后端选择、陌生平台或诊断结果与任务不一致时读取。由当前 Agent 选择并调用工具，不增加第二个调度服务。

## 从任务到候选

1. 确认目标 URL／查询、所需证据、时间范围及完整性。搜索列表、文章、评论、字幕、表格和画面分别判断；不把同平台的另一动作当作等价替代。
2. 优先检查用户指定来源、专用官方能力和已连接服务。平台命令从当前注册表／帮助发现；没有适用动作时，按需读取已安装 Agent Reach 的对应分类 reference，获取候选后再核对该工具的当前帮助。
3. 按授权环境、具体动作能力、当前依赖和数据外发条件筛选候选。上游默认排序与用户指定环境冲突时遵循用户；能力相当时优先已有配置、步骤更少且证据更直接的路径。
4. 执行最小有效查询，以实际输出判断任务是否完成。只为影响结论的缺口继续读取；按 [failure-domains.md](failure-domains.md) 排除共享失败依赖，保留已取得的证据。

`providers.json` 只保留现有适配的必要合约和任务边界，候选按数组顺序列出；顺序供条件相同时参考，不是自动降级链。台账未登记的工具可通过当前能力发现使用，不要求先修改文件。不得把资料中的命令模板直接作为 shell source 执行。

## 分开判断可用性与完成度

| 已取得的证据 | 可以判断 | 仍需核对 |
|---|---|---|
| 工具已安装、注册表有动作 | 当前版本暴露该动作 | 参数、授权与当前依赖 |
| bridge／Profile 就绪 | 该连接可用 | 目标站点账号、具体动作和内容 |
| doctor 返回 ok／active_backend | 该探针覆盖的条件通过 | 探测时间、实际账号及是否覆盖所需证据 |
| 命令成功返回内容 | 本次取得这些字段 | 目标、时效、完整性和来源是否满足问题 |

没有运行探针不能写成探针通过；`active_backend: null` 要结合报告判断是失败、未配置还是未验证。工具返回 `ok` 仍可能只有摘要。任务完成度由 Agent 按实际内容判断，不能让归一化 helper 替代语义验收。

## 职责与加载边界

| 承担者 | 负责 | 交回 Lookup 判断 |
|---|---|---|
| Lookup | 证据目标、候选选择、跨工具换路、完成验收 | 不实现站点抓取或浏览器协议 |
| OpenCLI／专用 CLI／连接器 | 当前命令、参数、执行、内部错误与资源生命周期 | 当前动作不足、需换环境或扩大数据范围 |
| Ego／宿主 Browser／DevTools | 所选环境内定位、等待、提取、交互、截图及原生收尾 | 登录／权限阻断、能力缺口、共享依赖失效 |
| Agent Reach | 按需提供平台候选资料、doctor 与已配置转写 | 不在本组合中重做总路由或固定多平台研究 |
| web-access | 当前作为方法来源；Proxy 未接入 | 后续证明独特执行收益后再评估 |

只将 Lookup 注册为自动触发的通用检索入口。保留上游包与原始路由描述；有竞争的通用 Skill 不加入客户端自动发现，选中后只读当前任务需要的执行资料。不要靠改写上游 description 消除冲突，也不把加载文档等同于启动第二个 Agent。

底层可在选定环境内完成普通定位、条件等待与执行恢复；Agent 重派业务动作仍遵循 [有界恢复](failure-domains.md#有界恢复)。换工具、浏览器或账号时，回到本文件与失败作用域判断；安装、Cookie 导出、费用和外发说明不构成额外授权。

Agent Reach 缺失时继续用现有 API、命令帮助与浏览器，不为了查候选安装它。诊断只在能消除具体不确定性时调用，不强制全平台体检。使用时的有界更新检查与维护统一见 [上游更新.md](上游更新.md)；不能将线上 main 的能力当成本机已安装能力。

## 新浏览器候选

轻舟等工具可作为专项候选，接入前核对当前 MCP schema、会话／run 生命周期、页面归属及关闭接口。只有直接浏览器工具可在当前环境独立调用时，才按普通工具使用；若必须启动内置 Agent，应明确模型调用、内容外发与费用条件，不能假定复用当前 Agent 登录或免费额度。

新候选需用同一目标证明解决了现有缺口，例如动态正文完整性或表格跨页提取，并验证退出、失败和收尾。未经实测不列为默认后端。OpenCLI 通用浏览器与 adapter 可能共享 bridge，不能作为该 bridge 故障的独立后备。
